# Sistema de Asistencia de Alumnos y Docentes

## Descripción
Proyecto desarrollado en Python como parte de un trabajo universitario para gestionar la asistencia de alumnos y docentes.

## Funcionalidades
- Registro de alumnos
- Registro de docentes
- Control de asistencia
- Consulta de registros

## Tecnologías utilizadas
- Python
- Git
- GitHub

## Objetivo
Desarrollar un sistema básico de gestión de asistencia aplicando conceptos de programación y estructuras de datos.
